<product_requirements>
The Bathroom Quote Saver.AI application is an AI-powered tool for generating detailed bathroom renovation quotes. It aims to provide contractors with a streamlined process for creating accurate, professional-looking quotes with a high-end UI/UX.

**Core Functionality:**
*   **AI-Driven Quoting:** Generates costs for over 70 granular sub-tasks across 10 categories.
*   **Project & Client Management:** Saves client details and entire project configurations.
*   **Dynamic Measurements:** Calculates floor area, wall area (net of doors), and perimeter from user-provided room dimensions (mm), with real-time updates.
*   **Cost Adjustments:** Allows users to manually override AI-estimated costs for each line item. The AI has a self-learning system to adapt to these changes.
*   **Multi-Area Projects:** Supports quoting for multiple separate areas (e.g., Main Bathroom, WC) within a single project.
*   **Output Generation:** Creates and emails professional PDF quotes (Scope of Works, Quote Summary), with an option to include or exclude a detailed cost breakdown.
*   **PWA:** Deployed as a Progressive Web App for a native-like mobile experience.

A major pending feature is an intelligent pricing system that uses uploaded supplier PDFs and web scraping to base quotes on real-time material costs.
</product_requirements>
